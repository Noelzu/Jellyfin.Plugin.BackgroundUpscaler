Background Upscaler

The scheduled task processes only local Backdrop JPG, JPEG, PNG and WebP images whose real file dimensions are exactly 1920 × 1080. Posters/Primary images, thumbs, logos and banners are never processed. Real-ESRGAN performs a 2× AI upscale and the result must validate as 3840 × 2160 before the original is replaced.

When disabled, the scheduled task exits without modifying files.

Affected libraries

Only Backdrop images belonging to checked libraries are eligible. If no libraries are checked, nothing is processed.
