# Background Upscaler 12.1.0.2

This release fixes the library-selection logic.

### What changed

- Fixed a bug where the plugin could show a selected library in Settings but scan **0 items** from it.
- Changed the Jellyfin library query to use the selected library as an ancestor, which correctly finds the media inside that library.
- The plugin can now actually scan the items belonging to the libraries you checked.

### In simple terms

If version 12.1.0.1 said it was scanning one selected library but found no items, this update fixes that. Your selected libraries now work as intended.
