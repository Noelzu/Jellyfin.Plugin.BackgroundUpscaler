# Background Upscaler 12.1.0.1

This is the first public release of Background Upscaler for Jellyfin 12.1.

### What it does

- Adds a Jellyfin scheduled task that looks for local artwork that is exactly **1920×1080**.
- Uses **Real-ESRGAN** to improve the image instead of simply stretching it.
- Produces a **3840×2160 (4K)** image and verifies the result before replacing the original.
- Lets you choose which Jellyfin libraries the task is allowed to scan.
- Lets you configure the Real-ESRGAN executable, model, model directory, GPU ID, tile size and TTA.
- Can keep a backup of the original image before replacing it.

### In simple terms

This first version gives Jellyfin a scheduled job that can turn supported 1080p artwork into AI-enhanced 4K artwork in the libraries you choose.
