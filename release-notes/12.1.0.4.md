# Background Upscaler 12.1.0.4

This is the main safety and usability update.

### What changed

- **Backdrop-only processing:** the plugin now ignores Primary/poster images, thumbs, logos, banners and every other non-Backdrop image type.
- Changed the recommended/default anime model to **`realesr-animevideov3`**, which proved much more reliable on lower-power Intel Vulkan GPUs during testing.
- Keeps original-image backups enabled by default for new configurations.
- Added **Single-image test mode**, which stops after one eligible Backdrop so you can safely test a model, GPU or tile size before processing a whole library.
- Added per-image timing to the Jellyfin log so you can see how long every upscale took.
- Improved log messages so they clearly identify Backdrop-only processing.
- Expanded the README with the required Vulkan/OpenMP container packages and a persistent custom-Docker-image setup.
- Documented the safer Intel-iGPU starting settings and the risk of block/tile corruption with heavier models on some GPUs.

### In simple terms

This version makes the plugin much safer. It only touches background images, gives you a one-image test mode, recommends the model that worked reliably in testing, and explains how to make the required Vulkan setup survive Docker container updates.
