# Background Upscaler 12.1.0.3

This release fixes Real-ESRGAN executable discovery inside Docker.

### What changed

- Changed the default Real-ESRGAN executable path to:
  `/opt/realesrgan/realesrgan-ncnn-vulkan`
- Added automatic fallback logic so a short executable name can resolve to the usual Docker mount under `/opt/realesrgan`.
- Removed the unavailable `realesrnet-x4plus` option from the model list.
- Kept the existing per-library, GPU, model and backup settings.

### In simple terms

The plugin no longer expects Real-ESRGAN to magically exist in the container's PATH. It now knows where the Docker-mounted executable normally lives, which prevents the "No such file or directory" startup error.
