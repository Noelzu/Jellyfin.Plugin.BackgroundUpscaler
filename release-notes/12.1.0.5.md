# Background Upscaler 12.1.0.5

This release adds optional 720p-to-4K Backdrop upscaling.

### What changed

- Added a new **"Also include exact 1280×720 Backdrops"** toggle.
- The toggle is **off by default**.
- Exact **1920×1080** Backdrops still use a **2×** Real-ESRGAN upscale to reach 3840×2160.
- When the new toggle is enabled, exact **1280×720** Backdrops use a **3×** Real-ESRGAN upscale to reach the same 3840×2160 target.
- Output is still verified as exactly 3840×2160 before the source image is replaced.
- Backdrop-only filtering, backups, single-image test mode and the safer `realesr-animevideov3` default remain in place.
- Updated the README and configuration page to explain the new 720p option.

### In simple terms

You can now optionally include 720p background images in the same job. Leave the new switch off if you only want 1080p Backdrops processed; turn it on if you also want exact 1280×720 Backdrops AI-upscaled to 4K.
